Search Console Audit Privacy Policy

Search Console Audit is a desktop tool operated by Andrey Sergeenkov to check how Google indexes and displays pages on sergeenkov.com.

Data access and use

The tool requests read-only access to Google Search Console. It reads the list of properties and permission levels to locate sergeenkov.com. For that site, it reads sitemap status, page indexing status, the canonical URLs Google chose, crawl dates, and search performance metrics such as impressions and clicks. The site owner uses these results to diagnose indexing issues and track search visibility.

Storage and sharing

The tool stores the OAuth refresh token in a local credentials file so it can run subsequent checks. It processes results locally. The site owner may review those results in a private assistant session. The tool does not publish or sell Google user data or use it for advertising.

Removing access

You can revoke access in your Google Account connections and remove the locally stored token and any saved reports. For questions or requests about your data, email andrey@sergeenkov.com.
