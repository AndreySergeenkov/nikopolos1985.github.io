# sergeenkov.com

Персональный сайт, размещённый на GitHub Pages.

## Структура

- `index.html` — главная страница
- `archive/index.html` — архив ранних публикаций в других изданиях; ссылки доступны для поиска по названию и изданию
- `style.css` — стили
- `feed.xml` — RSS лента
- `sitemap.xml` — шаблон карты сайта; GitHub Pages обновляет её из HTML-страниц при публикации
- `_includes/commission-box.html` — общий блок заказа исследования для главной и статей
- `images/` — изображения
- `*/` — статьи (каждая в своей папке)

Новые статьи размещаются в папках с `index.html`. После публикации GitHub Pages автоматически добавит их адреса в `/sitemap.xml`; вручную редактировать карту не нужно. RSS-ленту `feed.xml` при необходимости обновляют отдельно.

Ранние публикации в других изданиях добавляются в `archive/index.html`. На главной находится ссылка на этот архив; одинаковые URL в архиве не повторяются.

Чтобы изменить текст блока заказа исследования, правьте `_includes/commission-box.html`. Страницы с этим блоком обрабатываются Jekyll и содержат вызов `{% include commission-box.html %}` (или вариант `heading=true` для заголовка).

## Добровольная поддержка

`support/index.html` содержит адреса, валюты и сети. `_includes/support-prompt.html` — общий блок просьбы о поддержке на главной (`home=true`) и в конце статей. Оформление находится в `support/support.css`, копирование адресов — в `support/support.js`.

После изменения адреса в `support/index.html` обязательно заново создайте QR-коды: `py _scripts/generate-support-qr.py` (зависимость: `py -m pip install "qrcode[pil]"`). QR-коды в `support/qr/` содержат только соответствующий адрес, без суммы. Адрес в тексте, скопированное значение и содержимое QR-кода должны совпадать.

## Автоматический мерж

В проекте настроен автоматический мерж веток Claude в main.

### Как это работает

1. При push в любую ветку `claude/*` срабатывает GitHub Actions
2. Workflow автоматически мержит ветку в `main`
3. Изменения сразу попадают на сайт

### Конфигурация

Настройки находятся в `.github/workflows/auto-merge.yml`

```yaml
on:
  push:
    branches:
      - 'claude/**'
```

Мерж происходит от имени `github-actions[bot]` без создания Pull Request.
